# Nuvola dei risultati per widget (2026-10-23)

Il pannello Risultati riservato al presentatore supporta una quarta visualizzazione **Nuvola** per i widget domanda. L'editor salva `resultsView: "cloud"` nel singolo widget. Le etichette provengono dalle opzioni configurate e le dimensioni proporzionali dai conteggi per revisione; ogni elemento conserva il conteggio numerico accessibile. Le revisioni restano separate. È una nuvola di frequenze delle opzioni, **non** l'estrazione delle parole dalle risposte testuali libere. I risultati aggregati della pagina conservano barre/torta/tabella.

Build locali TypeScript/backend e Vite superate. Regressioni Node superate. Browser, screenreader, correttezza dati su PostgreSQL e sincronizzazione end-to-end non verificati; nessun gate RC viene chiuso.
