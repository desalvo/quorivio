## 26/10/2026 — Correzione precisione lease PostgreSQL: CI 40331628755 (hotfix non committato)
- **Errore reale:** quality gate `121602250100` fallito in `tools/ci_retention_postgres.mjs:69` sul test `physical file worker must acknowledge after actual unlink`. In precedenza erano **passati** 430 test Node, build frontend/backend, avvio, autenticazione e ciclo vita profili PostgreSQL. Il container gate è stato saltato per effetto del fallimento.
- **Causa:** PostgreSQL usa microsecondi nei `timestamptz`, mentre `pg` converte in `Date` JavaScript a precisione di millisecondi. Il lease tornato al worker non coincideva esattamente con quello salvato; dopo la rimozione fisica del file, ACK e retry potevano aggiornare zero righe. Il problema interessava anche avatar e directory di sessione.
- **Correzione:** `date_trunc('milliseconds', now()+interval '5 minutes')` nella presa in carico di **tutte e tre le code**. Confermati fencing sul timestamp esatto, protezione delle repliche, retry e cancellazione fisica; nessuna riduzione delle verifiche.
