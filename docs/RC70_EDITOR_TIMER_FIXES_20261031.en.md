# RC70 — Widget editing and page countdown

Timer widget duration is configurable in its property drawer (1–3600 s; 60 default). The shortest timer closes all audience interactions, with rehearsal/client state and an authoritative PostgreSQL-clock server mutation guard.

Proportional widget typography scaling preserves per-character face/color/style, geometry controls remain accessible outside clipping, attendee count stays presenter-only with fixture values in rehearsal, submitted rehearsal free-text is shown with sample statistics, and private presenter previews may show email while public disclosure requires opt-in.
