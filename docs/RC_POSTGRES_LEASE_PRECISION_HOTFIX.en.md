- **Root cause:** PostgreSQL `now()` returns microsecond-resolution timestamps, but `pg` decodes `timestamptz` into millisecond-resolution JavaScript `Date` objects. An outbox claim using `claimed_until=now()+interval '5 minutes'` produced an ACK/retry equality fence with a lossy roundtrip; a successfully unlinked file could therefore remain in the outbox. This also affected profile-photo and session-directory leases.
- **Fix:** claim leases using `date_trunc('milliseconds', now()+interval '5 minutes')` in **all three worker queues**. Keep exact equality fencing (`claimed_until=$n`), `FOR UPDATE SKIP LOCKED`, deadline/backoff and existing safety guarantees; do not weaken ACK predicates or skip the physical removal.
