# Presenter media widgets acceptance

1. Create a page with image, logo, video and PDF widgets, using real uploaded assets.
2. Save, start session and open the page.
3. In presenter projection inspect actual images/logo, usable video controls and PDF preview/open link.
4. Test geometry, rotation, resizing, switching pages, pause, close, reload and anonymous requests to inactive assets.
5. Test multiple browsers and at least two K8s replicas for authorization and synchronization.

**Not completed:** this is a test checklist, not browser/K8s test evidence.
