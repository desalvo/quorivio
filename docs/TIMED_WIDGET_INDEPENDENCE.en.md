# Independent timed quiz widgets — 2026-10-23

Each `timed-quiz` widget is now configured separately in the slide editor: options, single/multiple correct answers, and duration (5–600 seconds). Participant submissions use the existing widget-answer route and a distinct database row per participant, widget and revision. The answer deadline and elapsed milliseconds derive from the server-side page `opened_at` time; leaderboard reads are presenter-authenticated and segregated by widget/revision, ordered by elapsed time with deterministic ties, 20 entries per page. Only correct submissions qualify.

Implementation caveats: tests against live PostgreSQL, concurrent submissions, browser latency, page re-opening after pause, answer revision edit invariants, and real multi-browser synchrony have NOT been verified. Server receipt-time latency affects the ranking; this is not a latency-neutral contest. Existing `timed_quiz` activity rankings remain independent from widget rankings. The editor currently accepts editing of answer definitions after participation; validation of revision semantics remains an open release gate. PDF manuals have not been regenerated. RC closure remains at 67%.
