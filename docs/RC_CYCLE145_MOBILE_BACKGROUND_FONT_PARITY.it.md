# Quorivio 0.1.0-dev — RC145 — Correzione sfondo smartphone e uniformità Arial

La RC145 deriva dalla RC144 e conserva canvas smartphone indipendente da 390 px, Gradimento 0–9, geometria separata e relativa anteprima per partecipanti. È stato corretto un difetto effettivo: **caricando una nuova immagine come sfondo dalla modalità smartphone, il codice la applicava invece al background desktop**. Ora il caricamento aggiorna esclusivamente `page_design.mobile.backgroundAssetId`; il menu contestuale permette di scegliere uno sfondo dalla libreria, caricarne uno nuovo, cambiarne il colore o rimuovere l'immagine, senza modificare mai lo sfondo desktop. La scelta di un colore pieno cancella la precedente immagine mobile e rende visibile il colore. Se nessuno sfondo mobile è impostato, rimane il bianco.

Il font **Arial** default era già stato corretto in RC144; sono stati verificati i CSS effettivamente applicati e aggiunta una protezione sugli `h1`–`h4` dei widget affinché il font generale dell'applicazione (`Outfit`) non sovrascriva il font impostato nel widget. In Chromium, Arial 24 px nell'editor e nella preview produce stessa famiglia, dimensione e larghezza misurata; le porzioni di testo con formattazione esplicita mantengono il proprio font.

**Verifica locale:** suite Node API+web 825/825; quattro nuovi test Node; verifica Chromium CSS in headless, sfondo mobile isolato; contratti Python mirati ed inventario completi in fase di controllo. Restano la build Vite completa, la CI, l'upload autenticato in browser e il collaudo su telefoni reali. **Avanzamento certificato invariato all'85,25%** (43 gate accettati, 17 parziali), `rc_strict=false`, `publish_image=false`, `publish_latest=false`. Non è stata dichiarata una RC ufficiale. Nessun commit, push, pubblicazione Docker, accesso a server reali.
