# Widgets and 0–10 satisfaction

Version 0.1.0-dev; documentation build dev-20261022 (not revision/tag).

Palette includes rating, reactions, text, divider, demonstrative timer and demonstrative QR. Drag to reorder or use accessible arrows, then save. Rating is unique per participant and activity, server validated and aggregated per page and session. Timer and QR are not yet fully functional widgets. Real-world tests remain outstanding.
