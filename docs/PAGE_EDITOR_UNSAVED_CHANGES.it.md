# Protezione delle modifiche non salvate

L’editor segnala modifiche locali non salvate a widget, intestazioni e sfondi di pagina/risultati. Cambiare miniatura o chiudere l’editor richiede conferma quando il layout è modificato. Il browser avvisa anche prima di ricaricare o chiudere la scheda. Dopo un PATCH riuscito il layout non è più considerato modificato.

I test statici non sostituiscono una prova browser del comportamento; non è stato introdotto autosalvataggio.
