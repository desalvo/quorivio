# Keyboard access to canvas widgets

Focus a canvas widget using Tab. Arrow keys move by 1 percentage point. Shift+arrows resize width or height; Alt+arrows rotate by 5 degrees. Hold Ctrl for finer 0.1-point translation/resize or 1-degree rotation. Inputs and buttons keep their normal keyboard behavior. Geometry follows the existing save-page workflow; remember to save the page after editing. Browser and assistive-technology acceptance tests are still required.
