# RC162 — Editable smartphone editor and resilient QR widgets

The page editor has a visible, keyboard-operable sliding switch above the canvas, between Desktop 16:9 and Smartphone 390px. The phone layout uses the shared page widgets, content and styling, with responsive default vertical placement. Phone positions, background and per-widget font/size/color overrides are saved independently. Moving or resizing one phone widget persists only that widget's override; the other widgets continue to follow automatic defaults. A global “Restore automatic smartphone layout” and an individual position reset are available. Phone changes do not overwrite desktop positions. Autosave/backup/conflict logic retains the phone payload.

For QR widgets: the title is hidden by default, even for previously saved QR widgets without an explicit showTitle flag. The property “Show URL below QR code” defaults on and may be switched off without changing the actual QR destination. The URL comes from the server's existing QR endpoint; no guess is built from the session code. When enabled, the responsive grid reserves space under the code and allows long links to scroll, rather than disappearing when resized. The setting is serialized in the usual PageDesign and validated server-side only for QR widgets. The title can still be enabled and edited from the normal properties panel.

Acceptance: Node/TypeScript contract tests, negative mutation tests, computed Chromium resizing fixture (160x130, 110x95, 75x90, 290x220), history inventory and archive SHA-256 verification. Full npm compilation and authenticated editor/presenter/participant visual parity are still gated by GitHub CI and the administrator. No publish/deploy.
