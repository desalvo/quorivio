# Identità di versione e build

Versione applicazione: `0.1.0-dev`. Build documentale: `dev-20261022`. I manuali indicano versione e build documentale, mai revisione Git, SHA o tag release. Rigenerare quando cambiano le funzioni documentate o la build documentale, non per il solo tag. `dev-20261022` è un'etichetta di build documentale, non un'attestazione della build container.
