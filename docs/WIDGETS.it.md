# Widget e gradimento 0–10

Versione 0.1.0-dev; build documentale dev-20261022 (non revisione/tag).

La palette include rating, reazioni, testo, divisore, timer dimostrativo e QR dimostrativo. Trascinare per riordinare o usare le frecce accessibili; salvare il layout. Il voto 0–10 è unico per partecipante e domanda, validato dal server e aggregato per pagina e sessione. Timer e QR non sono ancora widget pienamente funzionali. Test reali mancanti.
