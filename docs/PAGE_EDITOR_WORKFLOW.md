# Session page editing

Select **Edit pages** from the session dashboard. The workspace fills the window, with vertically arranged page thumbnails, a horizontal widget palette and a central canvas. Create, duplicate, delete or reorder pages from the sidebar; dragging and arrow controls are supported.

**Warning:** page deletion also permanently removes associated responses. Save the canvas using **Save layout** before selecting another page. Use **Back to dashboard** to leave editing.

Blank page creation was fixed by matching the SQL placeholders to the bound parameters. The new authorized transactional DELETE endpoint clears the current published page when applicable, compacts positions and broadcasts the state.

Browser and Kubernetes acceptance remain outstanding.
