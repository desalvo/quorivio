# Canvas widget activity configuration — 0.1.0-dev

Select a `question` or `timed-quiz` widget on the canvas to configure question text, answer mode (single/multiple, plus free text/file for question widgets), up to twelve answer options, required answers, correct answers and timed quiz duration (5–600 seconds). Save the page layout to persist changes.

Widget IDs and the existing API payload format remain compatible. Server-side validation and live quiz mutation restrictions continue to apply.

**Pending acceptance:** a full frontend build with installed dependencies, browser create/edit/save/reopen tests, real participant quiz tests and Kubernetes verification. The legacy activity form remains available.
