# Quorivio — nuovo editor pagine contestuale (26 ottobre 2026)

Editor a schermo intero con grafica più professionale, sfondo fotografico locale non utilizzato nelle presentazioni, widget con sole icone e tooltip anche touch, miniature 16:9 selezionabili e riordinabili, menu della singola miniatura per creare prima/dopo, duplicare ed eliminare. Le impostazioni di pagina e dei widget sono menu contestuali nel canvas, non barre sopra il canvas. Persistenza invariata e prevenzione perdita bozze non salvate.

**Verifiche:** 135 test Python mirati PASS, parsing TypeScript TSX PASS, script browser validi sintatticamente; accettazione Chromium e build completa da eseguire in CI. RC 48,0% invariato, Docker opt-in, nessun commit eseguito.
